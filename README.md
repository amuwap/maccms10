# 苹果CMS一键安装说明

## 项目简介
苹果CMS是一款基于PHP和MySQL的视频内容管理系统，支持电影、电视剧、综艺、动漫等视频内容的管理和播放。

## 系统要求
- PHP 版本：7.4 - 8.5
- MySQL 版本：5.7 - 8.0
- Web服务器：Apache / Nginx
- 必要PHP扩展：pdo, pdo_mysql, fileinfo, curl, gd

## 一键安装方法

### 方法1：自动一键安装（推荐）
1. 上传整个项目到网站根目录
2. 在浏览器中访问：`http://你的域名/auto_install.php`
3. 系统会自动进行环境检测、数据库连接、SQL导入和管理员账号创建
4. 安装完成后会显示后台登录信息

### 方法2：传统安装向导
1. 上传整个项目到网站根目录
2. 在浏览器中访问：`http://你的域名/install.php`
3. 按照安装向导的步骤完成安装：
   - 同意用户协议
   - 环境检测
   - 填写数据库信息
   - 设置管理员账号
   - 完成安装

## 默认配置
- 数据库地址：127.0.0.1
- 数据库端口：3306
- 数据库名称：maccms10
- 数据库账号：root
- 数据库密码：（空）
- 数据库前缀：mac_
- 管理员账号：admin
- 管理员密码：admin123

## 注意事项
1. 请确保MySQL服务已经启动
2. 请确保root用户有创建数据库的权限
3. 安装完成后请及时修改默认密码
4. 建议修改后台入口文件名以提高安全性
